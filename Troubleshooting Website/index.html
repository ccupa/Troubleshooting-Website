CORE CONCEPTS


      
Think in layers, not guesses.


      

        A network problem becomes easier when you locate the first layer that
        fails.
      


      

        

          01

          
Device


          

            Is the adapter enabled? Did the device receive an IP address?
          

        


        

          02

          
Local network


          

            Can the device reach its default gateway and local services?
          

        


        

          03

          
Beyond the LAN


          

            Does DNS resolve names? Can traffic leave through the router?
          

        

      

    


    

      
COMMAND CARDS


      
Small commands, useful questions.


      

        Run a command only when you know what question it will answer.
      


      

        

          ipconfig /all

          
            What IP, gateway, and DNS settings did the device receive?
          
        


        

          ping 192.168.1.1

          
            Can the device reach its local default gateway?
          
        


        

          nslookup example.com

          
            Can DNS translate a name into an address?
