FIRST CHECK

Is the device connected to the network?

Look at the Wi-Fi or Ethernet indicator. We are checking the device’s local connection before testing anything farther away.

ipconfig /all
✦

Why start here?
Each check removes a category of causes. If the device has no local connection, a DNS test can only distract you.

CORE CONCEPTS

Think in layers, not guesses.

A network problem becomes easier when you locate the first layer that fails.

01

Device

Is the adapter enabled? Did the device receive an IP address?

02

Local network

Can the device reach its default gateway and local services?

03

Beyond the LAN

Does DNS resolve names? Can traffic leave through the router?

COMMAND CARDS

Small commands, useful questions.

Run a command only when you know what question it will answer.

ipconfig /allWhat IP, gateway, and DNS settings did the device receive?
ping 192.168.1.1Can the device reach its local default gateway?
nslookup example.comCan DNS translate a name into an address?
